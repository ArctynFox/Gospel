Contains the functional data for items.

Start of file is a list of addresses which refer to the byte locations of the start of each item's data.

# data segment
36 bytes long
2 bytes for item2 id
all stats are i16

# restrictions
0C 01 = estelle
0C 02 = joshua
0C 03 = scherazard
0C 08 = olivier
0C 10 = kloe
0C 20 = agate
0C 40 = tita
0C 80 = zin
0C FF = no restriction
0C AA = males only
0C 55 = females only

# types
01 00 = estelle only
02 00 = joshua only
03 00 = scherazard only
04 00 = olivier only
05 00 = kloe only
06 00 = agate only
07 00 = tita only
08 00 = zin only
0A 00 = armor slot
0C 00 = boots slot
0D 01 = accessory slot
0D 03 = accessory that changes art element

# accessory effects
01 00 = poison resist
02 00 = freeze resist
03 00 = petrify resist
04 00 = sleep resist
05 00 = mute resist
06 00 = blind resist
07 00 = seal resist
08 00 = confuse resist
09 00 = faint resist
0A 00 = deathblow resist
0B 00 = freeze and petrify resist
0C 00 = sleep and faint resist
0D 00 = all resist
00 01 = physical -> earth
00 02 = physical -> water
00 03 = physical -> fire
00 04 = physical -> wind
